# **Portfolio Website - Single Page Application**

A sleek and responsive portfolio website built using **ReactJS** and **Tailwind CSS**, designed to showcase your personal and professional information effectively.

![React](https://img.shields.io/badge/-React-blue?logo=react)
![TailwindCSS](https://img.shields.io/badge/-TailwindCSS-06B6D4?logo=tailwindcss)
![Responsive](https://img.shields.io/badge/-Responsive%20Design-lightgrey)
![Router](https://img.shields.io/badge/-React%20Router%20DOM-red?logo=reactrouter)

---

## 🚀 Features

- **Single Page Application** built with **ReactJS**
- Styled with **Tailwind CSS**
- Fully **responsive** across desktop, tablet, and mobile devices
- Navigation with **React Router DOM**
- **Download CV** button
- **Back to Top** button
- Contact form sends data via email with file upload support (`*.pdf`)

## 🧠 Sections Overview

### 📌 About Me
- Name
- Current position
- Personal description
- Contact email
- Social links: Facebook, Instagram, LinkedIn

### 🛠️ Skills
Grouped by:
- **Technical Skills** (Image + Title)
- **Knowledge Areas**
- **Languages**

### 🧳 Experience
- Role title
- Company/Organization description
- Date (Start to End)
- Position

### 📬 Contact
- Form fields:
  - Email
  - Subject
  - Message
  - File upload (`*.pdf`)
- Data is sent to your email via a configured mail service

### 📎 Footer
- Social icons
- Navigation links
- Copyright
